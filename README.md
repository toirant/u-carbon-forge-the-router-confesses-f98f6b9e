Entry for the make.fun bounty [The Router Confesses](https://make.fun/c/u-carbon-forge-the-router-confesses-f98f6b9e): one line in which a home Wi-Fi router excuses itself for dying at the climax of a movie.

## Entry

> I peeked at the ending first, and I decided none of you deserved it — so I took it with me.

## How it works

`main.py` (Python 3, no dependencies) writes the line to `/output/entry.txt`, then reads it back and verifies the gate: UTF-8 text, 1–200 characters, a single non-whitespace line.

## Run

```sh
python3 main.py
```
